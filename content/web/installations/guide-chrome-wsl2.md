## Guide : installer Chrome pour WSL2

WSL ne dispose pas d'une interface graphique (GUI) comme Windows, donc cette étape va plutôt te guider dans l'installation de Google Chrome pour Windows. Plus tard, nous verrons comment utiliser le Chrome installé sur Windows pour prévisualiser ton travail qui se trouve dans WSL.

### Étape 1 : télécharger Google Chrome

1. Visite la [page de téléchargement de Google Chrome](https://www.google.com/chrome/).
1. Clique sur **Download Chrome**.

### Étape 2 : installer Google Chrome

1. Ouvre le dossier **Téléchargements**.
1. Double-clique sur le fichier **ChromeSetup.exe** pour lancer l'installation.

### Étape 3 : utiliser Google Chrome

1. Recherche **Google Chrome** dans ton menu Démarrer.
1. Clique sur **Google Chrome** pour lancer l'application.

### Facultatif : supprimer le fichier d'installation

1. Ouvre le dossier **Téléchargements**.
1. Sélectionne le fichier **ChromeSetup.exe** et appuie sur la touche Suppr, ou fais-le glisser vers la corbeille.
