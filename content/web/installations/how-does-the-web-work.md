### Introduction

Avant d'apprendre à programmer pour le web, il est utile de comprendre plus précisément comment fonctionne le web. Ces notions donnent une vue d'ensemble de l'écosystème dans lequel tu vas travailler et te permettront d'échanger clairement avec d'autres développeurs.

### Aperçu de la leçon

Dans cette leçon, tu vas apprendre à :

- Décrire ce qu'est Internet.
- Décrire les paquets et leur rôle dans le transfert des données.
- Distinguer une page web, un serveur web, un navigateur et un moteur de recherche.
- Expliquer brièvement ce qu'est un client.
- Expliquer brièvement ce qu'est un serveur.
- Expliquer ce que sont les adresses IP.
- Expliquer ce que sont les serveurs DNS.
