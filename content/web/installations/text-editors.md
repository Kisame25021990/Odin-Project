### Introduction

Un éditeur de texte est l'outil que les développeurs utilisent le plus, quel que soit leur domaine. Un bon éditeur peut t'aider à écrire du code grâce à la vérification en temps réel, à la coloration syntaxique et au formatage automatique.

### Aperçu de la leçon

Dans cette leçon, tu vas découvrir :

- Ce que sont les éditeurs de code.
- Pourquoi ils sont utiles au développement.
- Comment installer Visual Studio Code (VS Code).

### Pourquoi ne puis-je pas utiliser Microsoft Word ?

Les traitements de texte comme Microsoft Word et LibreOffice Writer conviennent très bien à la rédaction de documents. Mais les fonctions qui permettent de mettre ces documents en forme les rendent inadaptés à l'écriture de code. Un document créé avec ces outils contient autre chose que du texte : des informations sur son affichage et sur les images qu'il contient. À l'inverse, les éditeurs de texte brut comme VS Code ou Sublime n'enregistrent pas ces informations supplémentaires. Le fichier ne contenant que du texte, d'autres programmes, comme l'interpréteur Ruby, peuvent le lire et l'exécuter comme du code.

### Les éditeurs de code

Tu peux voir les éditeurs de code comme des outils spécialisés pour le développement web. Ils sont personnalisables et proposent de nombreuses fonctions pratiques. Rien de plus frustrant que de chercher pendant deux heures pourquoi un programme ne fonctionne pas, pour découvrir qu'il manque une accolade fermante. Les extensions, la coloration syntaxique, la fermeture automatique des parenthèses et accolades, ainsi que l'analyse du code ne sont que quelques-uns des avantages d'un éditeur. Il en existe beaucoup, mais nous te conseillons de commencer avec Visual Studio Code.

**Visual Studio Code**, souvent appelé VS Code, est un excellent éditeur gratuit. Il propose de nombreuses extensions et s'intègre très bien à Git. C'est l'éditeur le plus utilisé par les élèves et les modérateurs d'Odin ; tu trouveras donc facilement de l'aide dans la communauté.

Le choix d'un éditeur dépend généralement de tes préférences. Pour ce cursus, nous partirons du principe que tu utilises VS Code, car il est gratuit et fonctionne de façon similaire sur tous les systèmes d'exploitation. Garde à l'esprit que la communauté ne pourra pas forcément t'aider si tu choisis un autre éditeur.

Si tu travailles dans une **machine virtuelle**, installe VS Code **dans cette machine**. Tu peux aussi l'installer sur ton ordinateur hôte (par exemple, Windows), mais assure-toi d'avoir cet outil essentiel dans la machine virtuelle.
