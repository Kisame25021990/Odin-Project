### Introduction

Savoir utiliser les outils de développement du navigateur est essentiel pour tout développeur web. Ils permettent d'exécuter du JavaScript, de modifier le HTML et le CSS sans actualiser la page et de consulter des données de performance. Ils font aussi gagner beaucoup de temps. Tu les as déjà utilisés pour déboguer et travailler sur le HTML et le CSS ; voyons comment ils peuvent t'aider avec JavaScript.

### Aperçu de la leçon

- Modifier la taille d'affichage d'un site avec les outils de développement.
- Afficher et modifier le DOM.
- Déboguer du JavaScript et utiliser des points d'arrêt.
- Afficher et modifier le HTML dans l'onglet Elements.
- Consulter le panneau Resources pour voir les scripts d'un site.
- Ajouter un pseudo-état CSS à une classe.
- Afficher les propriétés CSS par ordre alphabétique.
- Afficher et modifier le modèle de boîte d'un élément dans Chrome DevTools.
- Afficher une page en mode impression.
- Activer et désactiver des classes CSS.
- Simuler des requêtes média en mode appareil.

### Ouvrir DevTools

Il existe trois façons d'ouvrir les outils de développement de Chrome :

1. Dans le menu Chrome, choisis More Tools > Developer Tools.
1. Fais un clic droit sur une page web et sélectionne Inspect.
1. Utilise le raccourci <kbd>F12</kbd> ou <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd> (Mac : <kbd>Opt</kbd> + <kbd>Cmd</kbd> + <kbd>C</kbd>).
