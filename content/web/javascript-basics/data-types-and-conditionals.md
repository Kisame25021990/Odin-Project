### Introduction

JavaScript comporte plusieurs types de données courants. Ces leçons fondamentales te donneront de bonnes bases pour les comprendre. Avant d'approfondir, lis cette [présentation des types de données JavaScript les plus courants](http://javascript.info/types).

### Aperçu de la leçon

- Nommer les huit types de données de JavaScript.
- Distinguer les guillemets simples, doubles et inverses.
- Insérer une variable ou une expression dans une chaîne.
- Comprendre ce qu'est une méthode.
- Nommer les trois opérateurs logiques.
- Comprendre les opérateurs de comparaison.
- Comprendre les conditions et l'imbrication.
- Comprendre les valeurs *truthy* et *falsy*.

### Chaînes de caractères

Selon le travail que tu effectues, tu manipuleras peut-être davantage du texte que des nombres. Une **chaîne de caractères** est un morceau de texte et un élément fondamental du langage.

1. Lis et reproduis les exemples du [tutoriel MDN sur les chaînes JavaScript](https://developer.mozilla.org/en-US/docs/Learn/JavaScript/First_steps/Strings). Ignore la section « Concatenation in context », qui traite de notions abordées dans une leçon ultérieure sur la manipulation du DOM.
1. Parcours la leçon de W3Schools sur les [méthodes des chaînes](https://www.w3schools.com/js/js_string_methods.asp). Une **méthode** est une fonctionnalité intégrée au langage ou à un type de données particulier.
1. Il existe bien d'autres méthodes intégrées. Tu n'as pas besoin de toutes les lire ni de les mémoriser, mais garde à portée de main la [documentation MDN sur les chaînes](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String), qui fournit des explications détaillées et une référence complète.

### Conditions

Passons aux choses intéressantes ! Jusqu'ici, nous avons surtout fait des opérations qu'on pourrait aussi réaliser avec des calculs simples. Programmer, c'est surtout apprendre à l'ordinateur à prendre des décisions pour résoudre des problèmes plus complexes. Les conditions permettent de faire cela. Lis les ressources suivantes :

1. Pour étudier les conditions, commence par bien comprendre les [comparaisons](http://javascript.info/comparison).
1. L'article MDN sur les [conditions](https://developer.mozilla.org/en-US/docs/Learn/JavaScript/Building_blocks/conditionals) présente plusieurs façons d'écrire du code conditionnel.
1. La leçon de JavaScript.info sur [if/else](http://javascript.info/ifelse) reprend ces notions et propose des exercices à la fin.
1. Parcours la leçon de JavaScript.info sur les [opérateurs logiques](http://javascript.info/logical-operators). Dans les exercices, tu verras parfois l'appel alert() avec un nombre ou une chaîne entre parenthèses. Nous étudierons cette instruction plus tard. Certaines réponses peuvent sembler déroutantes pour le moment, mais elles sont correctes ; tu comprendras en avançant dans le cursus.
1. Découvre l'instruction [switch](https://javascript.info/switch), pratique lorsqu'il faut traiter plusieurs conditions.
