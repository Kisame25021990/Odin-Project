## HTML et CSS

Le HTML et le CSS sont deux langages qui travaillent ensemble pour créer tout ce que tu vois lorsque tu consultes quelque chose sur le web. Le HTML est la donnée brute à partir de laquelle une page web est construite. Tous les textes, liens, cartes, listes et boutons sont créés en HTML. Le CSS, lui, ajoute du *style* à ces éléments bruts. Le HTML place l'information sur une page web, et le CSS positionne cette information, lui donne de la couleur, change la police et la rend agréable à regarder !

Beaucoup d'excellentes ressources continuent de présenter le HTML et le CSS comme des *langages de programmation* (**programming languages**), mais si on veut être rigoureux, cette étiquette n'est pas tout à fait exacte : ils ne s'occupent que de présenter de l'information. Ils ne servent pas à programmer une quelconque logique. Le **JavaScript**, que tu apprendras plus tard dans le cours, est un langage de programmation, car il sert à faire agir les pages web. Pourtant, on peut déjà faire beaucoup de choses avec le HTML et le CSS seuls, et tu auras absolument besoin des deux. Les leçons suivantes visent à te donner les outils nécessaires pour réussir lorsque tu arriveras au contenu JavaScript, au fil de ton avancement dans le cursus !
